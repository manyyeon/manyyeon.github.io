Research

Accelerating Quantum LDPC Code Optimization Through Adversarial Games

Manuscript in preparation

Dayeon Yoo and Milad Marvian

We designed an adversarial-game framework in which a code optimizer updates quantum LDPC codes against an environment that identifies minimum-weight undetectable errors. The framework optimizes hypergraph-product and bivariate bicycle codes.
